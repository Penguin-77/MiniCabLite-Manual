  • 概述

概述

MiniCab Lite 是 JAKA 推出的基于宽电压直流供电、体积小巧的机器人控制柜。可集成到AGV、复合机器人等移动平台、并支持密集部署。

MiniCab Lite 可搭配MiniCobo、Mini2和Mini2C机器人使用。
